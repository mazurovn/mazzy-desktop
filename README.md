# Mazzy Desktop

Рабочий стол Mazzy на Ubuntu. Две сессии входа: **Mazzy OS Mango** и **Mazzy OS Hyprland**.
Оболочка одна — `mazzy-shell` (Nim, слой Wayland). Noctalia не стартует.

```
install.sh              пакеты и симлинки ~/.config
config/hypr/            конфиг сессии Hyprland
config/mazzy/           settings.json, язык; док и обои — локальные файлы
config/applications/    пункт настроек Mazzy
src/                    Nim, Mojo, Go, MoonBit — см. src/README.md
system/                 Bluetooth и prime-run
wallpapers/             обои в ~/Pictures/Wallpapers
```

Примеры локальных файлов: `config/mazzy/dock.example` и `config/mazzy/wallpaper.example`.
Свои `dock` и `wallpaper` в репозиторий не входят.

Бар и док рисует `mazzy-shell`. Бар — бумага выбранного стиля, активный стол цветом акцента.
Док — плашка со значками и тонкой линией акцента. Подписи по умолчанию выключены: имя появляется под курсором.
Плотность 40…100 пишет `chrome.opacity` и красит бар, док и листы. 100 — сплошная бумага.
Стили: Бумага, Чернила, Рассвет. Правый ряд виджетов переставляется в разделе «Виджеты» (правка) и на странице «Оформление». Столы и часы остаются на своих местах.
Лист закрывается щелчком снаружи или после ухода курсора. Задержка — «Закрытие листа»
на странице «Оформление», 0…3000 мс. Ноль оставляет только щелчок снаружи.

Знак раскладки берётся из живого ответа композитора. На Mango это `get keyboardlayout`.
Пустой ответ знака не рисует. Сбой сокета прошлый знак не стирает.
Лист «Сессия»: блокировка сразу, сон, выход и выключение — второй щелчок по той же строке.
Выход без номера сессии лист не закрывает.

Ночной ползунок не рисуется, пока нет пакета `wlsunset`.
Меню оболочки — три раздела: «Управление», «Приложения», «Виджеты».
Значок сетки справа открывает управление, знак слева и первый значок дока — приложения.
Плитка появляется, когда чтение уже есть: звук, свет, сеть, Bluetooth, микрофон, профиль,
тишина, медиа, батарея, VPN. Если playerctl видит плеер, «Назад», «Медиа» и «Дальше» стоят одной строкой в этом же листе. Чип медиа на баре открывает это меню, отдельный лист справа не открывается. Снимок — если стоит `grim`. Буфер — только когда виджет буфера включён.
«Стиль» переключает бумагу. «Плотность» — ползунок 40…100 в том же меню.
Процессор, память и канал рисуются, только когда /proc дал второе чтение. Делений сигнала нет.
Щелчок по часам открывает календарь, режим часов и сессию. Блокировка сразу, сон и выключение — второй щелчок.
Поиск сужает приложения, Enter запускает единственное совпадение. «Все приложения» открывает fuzzel.
Погода и ночь в меню не рисуются.

## Горячие клавиши Hyprland (Super = ⌘)

| Клавиши | Действие |
|---|---|
| Alt Space | Лаунчер fuzzel |
| ⌘ Tab / Alt Tab | Карусель окон. На Mango снимок самого окна, не экрана: выбранная карточка и два соседа |
| ⌘ Enter / ⌘ E / ⌘ B | Терминал / Файлы / Браузер |
| ⌘ S | Настройки Mazzy |
| ⌘ N | Вернуть уведомление mako |
| ⌘ V | История буфера через fuzzel |
| ⌘ W | Следующие обои |
| ⌘ Q / ⌘ F / ⌘ M | Закрыть / полный экран / максимизировать |
| ⌘ H | Убрать окно на скрытый стол |
| ⌘ 1…9, Ctrl ←/→ | Рабочие столы |
| Print / ⌘ Print | Область / весь экран в буфер |
| ⌘ L | Блокировка swaylock |
| ⌘ Shift Q | Меню сессии fuzzel. Значок сессии на баре открывает лист оболочки |
| ⌘ D | Показать или скрыть док |

Раскладка us/ru на Hyprland — xkb, переключатель `grp:win_space_toggle`.
На Mango живая группа читается отдельно от строки `xkb_rules_layout`.

## Настройки

`mazzy-settings` — центр настроек. Эффекты Hyprland пишутся в `conf/mazzy-effects.conf`
и зовут `hyprctl` только когда сессия — Hyprland. На Mango этот вызов не делается.
Подсветка пишется через logind, не в sysfs напрямую.

Композитор Hyprland рисует через Intel (`AQ_DRM_DEVICES` в `conf/env.conf`).
Программа на NVIDIA: `prime-run`. Глобальный фильтр EGL на всю сессию не ставится:
он ломает PRIME. Mesa задаётся только процессу `mazzy-shell`.

Bluetooth: `system/`. Установка правила — `pkexec sh system/install-bluetooth.sh`.
